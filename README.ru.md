# podkop-exp

[English](README.md)

Репозиторий для тестов новой функциональности [podkop](https://github.com/itdoginfo/podkop). То,
что проверяется здесь, может потом войти в podkop, измениться или исчезнуть.

podkop-exp ставится вместо podkop и сохраняет его файл настроек (`/etc/config/podkop`) и страницу в
LuCI. Бэкенд — одна программа на Go с sing-box внутри, отдельный пакет sing-box не нужен.

## Что добавляет к podkop

- **Один бэкенд с движком внутри.** Страница спрашивает работающий бэкенд, поэтому почти не
  нагружает роутер. Если бэкенд падает раз за разом, роутеру возвращается его собственный DNS.
- **Движок — [podkop-engine](https://github.com/podkop-net/podkop-engine)**, сборка sing-box.
  Работает с современными серверами Xray (REALITY с X25519MLKEM768), умеет транспорт XHTTP и
  шифрование VLESS.
- **Серверы отдельно от правил.** Подписки, ссылки, Outbound JSON и интерфейсы — на вкладке
  «Серверы». Правило берёт из них серверы по словам в именах и может подключаться через другой
  источник.
- **Подписки скачивает сам роутер.** Идентификатор устройства (HWID) берётся из железа. Видны трафик
  и срок подписки. Изменение списка не перезапускает sing-box, так что открытые соединения
  остаются.
- **Автовыбор сервера в каждом правиле:** самый быстрый, самый быстрый с учётом потерь или
  балансировка между лучшими. Запасные («Напрямую», «Блокировать», другие серверы) включаются,
  когда не отвечает ни один сервер. Сервер можно закрепить на дашборде.
- **Детектор блокировок и обход.** У неработающего сервера видна причина (нет ответа, заморозка,
  лимит, нет пути …). «Проверить» проверяет сервер и может предложить обход: маску сайта из белого
  списка, разбиение ClientHello на две записи или подключение через другой сервер.
- **Автосмена отпечатка uTLS, включена по умолчанию.** Сначала пробуется отпечаток TLS из ссылки
  без ключа X25519MLKEM768, на котором ТСПУ замораживает соединения, затем firefox, затем отпечаток
  как есть. Первый прошедший запоминается для сервера.
- **Загрузки, которые доходят.** Списки и подписки, которые не приходят напрямую, приходят через
  серверы ваших правил. Сначала пробуется путь, который сработал в прошлый раз.
- **DNS:** несколько серверов (DoH, DoT, UDP, DNS провайдера; IPv4 или IPv6) — по порядку или
  сначала самый быстрый; в ответах сначала IPv4, только IPv4 или оба. DNS провайдера — запасной, на каждом аплинке. После перезагрузки dnsmasq
  по-прежнему отправляет запросы podkop. Перенаправления отдельных доменов (Tailscale) сохраняются.
- **BitTorrent:** настройка отправляет его мимо podkop, блокирует или отправляет через серверы
  правила — для того, что берёт podkop, или для всей сети, и для клиента на самом роутере. Его
  статистика — на дашборде. Чего он не умеет — в [руководстве](docs/GUIDE.ru.md#bittorrent).
- **Дашборд и диагностика:** маршрут каждого правила, серверы с задержкой и потерями, трафик
  BitTorrent. Глобальная проверка смотрит ещё часы роутера, состояние dnsmasq, выбор сервера и
  подсказывает MTU для VPN-интерфейсов.
- **IPv6:** мимо podkop или через него — для подсетей IPv6 из списков, как IPv4
  ([руководство](docs/GUIDE.ru.md#ipv6)).
- **Несколько аплинков:** работают mwan3 (балансировка и резерв), PPPoE, маршруты к отдельным хостам
  и Tailscale.
- **YACD в пакете**, открывается только с выбранных устройств.
- **Настройки podkop переводятся** при установке, прежний файл остаётся, чтобы можно было вернуться.

## Установка

OpenWrt 24.10 или новее, не меньше 80 МБ оперативной памяти. В консоли роутера:

```sh
sh <(wget -O - https://raw.githubusercontent.com/podkop-net/podkop-experimental/main/install.sh)
```

Установщик проверяет роутер. Он предлагает удалить podkop и пакеты, которые конфликтуют с
podkop-exp, а если не хватает места на флеше — и ненужные podkop-exp пакеты sing-box. Затем ставит
podkop-exp и его страницу, по желанию — с русским переводом. Настройки podkop переводятся в формат
podkop-exp, прежний файл остаётся как `/etc/config/podkop.pre-0.8.8`.
Он показывает вывод каждой команды по ходу дела и сообщает, если сервер не отвечает. Без русского
перевода и без вопроса о нём — добавьте `--no-ru` в конец команды (`--ru` ставит перевод без
вопроса).

Обновление — та же команда. После обновления очистите кэш браузера для страницы LuCI.

## Вернуться на podkop

Удалите пакеты (`luci-i18n-podkop-exp-ru` — только если ставили перевод):

```sh
opkg remove luci-i18n-podkop-exp-ru luci-app-podkop-exp podkop-exp   # OpenWrt 24.10
apk del luci-i18n-podkop-exp-ru luci-app-podkop-exp podkop-exp       # OpenWrt 25.12
```

Верните прежние настройки командой `mv /etc/config/podkop.pre-0.8.8 /etc/config/podkop` (если такого файла нет, удалите
`/etc/config/podkop`). Затем поставьте podkop по его README.
